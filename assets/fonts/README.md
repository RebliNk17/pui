# Font fallbacks

`NotoSansHebrew.ttf` is Noto Sans Hebrew, distributed under the SIL Open Font License 1.1 (see `OFL-NotoSansHebrew.txt`). It is embedded as a fallback so Hebrew glyphs are available even without platform fonts. Existing Latin typography is unchanged.

Source: https://github.com/google/fonts/tree/main/ofl/notosanshebrew
Downloaded file: `NotoSansHebrew[wdth,wght].ttf`
SHA-256: `7ef36a2c3593758cdb622e1bdef4f84523e92fbc3ccc667438dd80ff54c2de88`

Other language fallbacks are loaded from installed fonts at startup; proprietary platform fonts are never redistributed. Glyph coverage does not imply bidirectional layout or complex-script shaping support in egui.
